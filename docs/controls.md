# Controls

The AirPig editing experience is intended for keyboard and mouse. It may be possible to create mappings for devices such as the Steam Deck but this is not directly supported as of the AirPig Alpha release.

AirPig can be played with a keyboard or a gamepad. Playtesting your game with a keyboard is convenient but we recommend using a controller for actual gameplay as it's a more enjoyable experience!

{% hint style="info" %}
We intend to offer better keyboard and mouse controls, wide gamepad support, local multiplayer, configurable controls, and potentially even touchscreen input in future versions of AirPig. The current controls are a functional Alpha implementation, not our target experience!
{% endhint %}

### Gameplay Controls

#### Keyboard Controls

* **Movement**: `WASD`
* **Attack**: `Space`
* **Dash**: `Shift`
* **Journal**: `J`
* **Inventory**: `I`
* **Interact**: `F`
* **Exit Playtest**: `Esc`
* **Show Debug Info**: `CTRL + D`

#### Gamepad Controls

AirPig should support most controller types. The controls listed below are based on Xbox controller buttons but should map to the same location on other controller types:

* **Movement**: `Left Analog Stick`
* **Attack**: `X Button`
* **Dash**: <kbd>B Button</kbd>
* **Journal**: `Left Shoulder Button`
* **Inventory**: `Right Shoulder Button`
* **Interact**: `A Button`
* **Exit Playtest**: `Not Implemented`

### Editing Controls

These are shared shortcut keys in most editing contexts. You can see an in-editor reference to these keys by clicking the question mark in the top right of the editor.

* **Duplicate**: `D`
* **Flip** (horizontally): `X`
* **Delete**: `Delete`
* **Snap to Pixel**: `Shift`
* **Zoom**: `Mouse Wheel`
* **Pan**: `Middle Mouse Drag`
* **Rotate Object**: `Alt`
* **Rotate Object With Snapping**: `Alt + Shift`

#### Polygon Editing

* **Add Node**: `+`
* **Remove Node**: `-`
* **Recalculate Centroid**: `C`
